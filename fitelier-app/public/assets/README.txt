FITELIER CATALOGUE IMAGE SET

Eight images extracted from the first approved Fitelier Collection concept render.
Use these on the existing collection cards, in this order:
Suits, Trousers, Jackets, Knitwear, Waistcoats, Shirts, Denim, Outerwear.

Copy the eight .webp files to fitelier-app/public/assets/catalogue/
Then add the CSS rules in catalogue-images.css to the end of the website stylesheet (or load it after existing styles).

These are concept-image crops, not original camera photographs. They should be reviewed at full size before publication.
